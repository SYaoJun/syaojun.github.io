# DB &amp; Systems 实战学习站

个人学习资源导航站，整理 CMU 15-445 数据库系统课程资料，按学期分类存放讲座与视频入口。

## 页面

- `index.html` —— 个人简介主页
- `lectures.html` —— 讲座与视频总览（学期列表）
- `lectures-2022-fall.html` / `lectures-2023-spring.html` / `lectures-2025-fall.html` / `lectures-2026-spring.html` —— 各学期课程表
- `about.html` —— 课程介绍与 FAQ

## 技术栈

纯静态 HTML + CSS + 原生 JavaScript，无构建依赖，直接打开或用任意静态服务器托管即可。

```bash
# 本地预览
python3 -m http.server 8000
```
